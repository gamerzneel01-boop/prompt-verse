FAQ

Common questions

Is Prompt-Verse free?

Yes. This v3 is a free browser-based starter version.

Does Prompt-Verse use real AI?

Yes. When deployed with the secure server-side API configuration, the main generator and Prompt Improver use a real AI model. A local fallback keeps the UI usable if the API is unavailable.

Are my saved prompts uploaded?

No. Favorites and history are stored in your browser's local storage in this starter version.

Is my API key safe?

Your OpenAI key belongs in the server environment as OPENAI_API_KEY. It should never be placed in index.html or browser JavaScript.

Can Prompt-Verse become a full AI SaaS?

Yes. Authentication, usage limits, billing, analytics and a database can be added on top of this backend.
