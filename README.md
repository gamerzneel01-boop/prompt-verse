# Prompt-Verse v3 Advanced

A modern browser-based AI prompt toolkit.

## Included
- AI Prompt Generator
- Prompt Improver
- Prompt Builder
- AI Image Prompt Builder
- Prompt Score (local heuristic)
- Trending prompt cards
- Specialized prompt tools
- Chat / Image / YouTube / Coding / Business categories
- Favorites and local history
- One-click copy
- Dark/light mode
- Responsive design
- SEO metadata
- Existing About, Blog, Contact, Privacy, Terms and Disclaimer pages

## Important
This v3 starter uses local JavaScript templates. It does NOT expose or require an AI API key.
For real AI generation, connect a secure server-side API later.

## Run
Open `index.html` with VS Code Live Server.
